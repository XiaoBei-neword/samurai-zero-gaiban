# 武士零 · 丐版（Samurai Zero - Gaiban）

> 原生 JavaScript + Canvas 2D + Web Audio 手写的**像素风**赛博朋克武士横版动作游戏。
> 四关、一击必杀、时间减缓、子弹反弹，**零第三方依赖**，全部美术与音效在运行时程序化生成。

本项目由 DeepSeek v4.1 Flash 辅助开发，是《武士零》的同人简化版（"丐版"）。

---

## 快速开始

### Windows：双击 `启动.cmd`

它会做三件事：定位自身目录 → 用系统 Node.js 起一个本地静态服务器（只监听 `127.0.0.1`，端口从 8123 起自动避让）→ 自动用默认浏览器打开游戏。

启动后**立即进入第一关**，没有主菜单、没有开场动画、没有加载条。

### 任意平台：一行命令

```bash
node server.mjs
```

然后访问终端里打印的地址（默认 `http://127.0.0.1:8123/index.html`）。

**前置条件**：Node.js 18+（仅用于把磁盘文件发给浏览器，不做编译转译）。
关闭那个命令行窗口即可停止服务器。

> 为什么需要本地服务器：游戏用 ES Module 组织代码，浏览器禁止 `file://` 加载模块。

## 核心设计

- **一击必杀**：敌人与玩家同归于尽的判定规则在 `director.js` 的 `killPlayer()` 中统一处理。
- **时间减缓**：按住减速键时全局时间缩放，同时清空积分器，恢复时不补帧。
- **冲刺无敌**：`invulnT > 0` 期间对子弹、敌人的刀、盾撞、地刺、手雷爆炸全部免疫。
- **像素风**：世界渲染在 1/3 分辨率的场景画布上，再 3x 最近邻放大；角色与道具按像素格对齐拼装；敌人子弹为金色菱形颗粒 + 淡金光晕，零拖尾。
- **死亡流程**：红闪 → 全屏暗红压边 + 大字「任务失败 / MISSION FAILED」→ 2 秒倒计时进度线 → 无缝重置本关，死亡次数照常累加。
